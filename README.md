# NammaHomestay

NammaHomestay is an Android application developed to help users discover, explore, and book homestays easily. The app provides a simple and user-friendly interface for browsing available stays, viewing details, and managing bookings efficiently.

---

## Features

- User-friendly Android application
- Browse available homestays
- View homestay details with images and descriptions
- Booking functionality
- Clean and responsive UI
- Firebase integration for backend services
- Secure user authentication
- Real-time data handling

---

## Technologies Used

- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Realtime Database / Firestore
- Jetpack Compose / XML UI
- Gradle

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Kushal112-code/NammaHomestay.git
```

2. Open the project in Android Studio.

3. Sync Gradle files.

4. Run the application on an emulator or Android device.

---

## Usage

- Register or log in to the application
- Browse available homestays
- View property details
- Book your preferred homestay
- Manage bookings easily
